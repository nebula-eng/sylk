# 常见问题

## 安装与启动

**双击安装包，Windows 提示「未知发布者」**
安装包没有代码签名，这是预期行为。点「更多信息 → 仍要运行」。公司电脑有软件白名单时，需要先让 IT 放行。

**双击没反应，或者打开是白屏**
先确认 WebView2 运行时已安装（Windows 11 通常自带）。再看
`%LOCALAPPDATA%\app.sylk.desktop\logs` 下当天的日志。仍无法启动时，从开始菜单启动一次，
排除快捷方式问题。

**为什么只有一个窗口**
Sylk 是单实例应用：重复双击会把已有窗口叫到前台，不会再启动一个引擎和数据库连接。

**关闭窗口后去哪了**
默认最小化到托盘（可在设置 → 外观关闭）。托盘图标可以重新打开或退出。

## 引擎与登录

**Sylk 为什么不带引擎**
NapCat、V8 兼容引擎包和 QQ 客户端都受各自的第三方许可限制，不能随本仓库或安装包分发；
上游公开下载源目前也已失效。引擎需要你自备，获取渠道与目录结构见
[`engine.md`](engine.md)。这是第一次使用唯一的额外步骤。

**自动查找找不到引擎**
自动查找只扫下载、桌面、文档、`%LOCALAPPDATA%\Sylk` 和各盘根目录，最多两层子目录、
3 秒上限。引擎放在别处就用「指定引擎目录」直接选。

**QQ 弹「文件已损坏」**
QQ 版本与引擎不匹配。经典 NapCat 注入不适用于 QQ 9.9.37-54395 及以上，需要 V8 兼容引擎包。
Sylk 启动前会比对版本，不匹配时不会注入，登录页会写出两边版本。

**二维码空白，或者一直显示「正在启动」**
如果之前登录过，Sylk 会先尝试快速登录；60 秒没有进展会自动清理快速登录标记并改用扫码。
也可以点一次「刷新二维码」。不要连续重启引擎。

**扫码提示「当前扫码操作存在安全风险」**
腾讯账号侧的风控，不是 Sylk 报错。先停引擎，不要连续重试；等 10–30 分钟，确认手机 QQ
本身登录正常，在常用网络下再扫一次。登录后也不要频繁退出/重启引擎。

**登录成功但界面没反应**
0.2.7 起已修复接口 token 与引擎配置不一致的问题。若仍出现，升级到最新版，并检查
设置 → 引擎看状态与日志，能看到探活失败原因。

**能用外部 NapCat 吗**
可以。设置 → 引擎 → 接入方式选「外部 NapCat」，再到「连接」页填 HTTP、WebSocket 地址和 token。
外部模式下 Sylk 不负责启动引擎。

## 同步与下载

**为什么只同步到最近一批历史**
只能读到当前账号在客户端里还看得见的记录；超过服务器保留期的，任何工具都拿不回来。
把设置 → 媒体库里的「单会话最多同步页数」调大能多翻一些。

**语音显示「音频还没下载」**
索引有这条，文件没落地。去任务队列看原因：多数是 QQ 语音链接过期，或引擎侧缺解码能力。
点「重试失败」，或重新同步该会话。

**刚发的语音没出现**
实时监听依赖引擎的 WebSocket 连接。先看连接状态；然后在会话里点一次「同步」。
如果历史列表能拉到但语音没入库，把任务队列的失败原因和日志一起提 issue。

**空会话同步报「消息undefined不存在」**
NapCat 对没有历史消息的会话会返回这个提示。0.2.7 起按空会话处理，不会中断同步。

**头像不显示**
群/好友头像来自 QQ 头像 CDN（`q*.qlogo.cn` / `p.qlogo.cn`），需要网络可达。
头像被 CSP 拦截的问题已在 0.2.5 修复；升级到最新版即可。

## 转写

**本机转写怎么配**
最简单的步骤：

1. 在 PowerShell 运行：
   ```powershell
   $s = "$env:TEMP\setup-asr.ps1"
   Invoke-WebRequest https://github.com/nebula-eng/sylk/releases/latest/download/setup-asr.ps1 -OutFile $s
   powershell -ExecutionPolicy Bypass -File $s
   ```
   下载失败时，打开仓库 `scripts/setup-asr.ps1`，复制内容到本机 `.ps1` 后运行。
2. 打开 设置 → 转写，启用。

脚本会把 `whisper-cli.exe`、依赖 DLL 和 `ggml-base.bin` 放到
`%LOCALAPPDATA%\Sylk\tools`，Sylk 自动识别，不需要手填路径。
源码用户也可以直接运行 `npm run setup:asr`。默认 base 模型约 141 MB；中文建议
`-Model small` 或 `-Model medium`。GitHub 仓库和安装包不包含 whisper 文件。

**云端转写安全吗**
音频会发送到你填写的 OpenAI 兼容接口。地址必须是 HTTPS（本机回环地址例外），
API Key 用 Windows DPAPI 加密后保存在设置文件里。不需要云端转写就不要开启。

**转写失败怎么办**
任务页有失败原因；修好路径/接口后在任务页点「重试失败」。单条语音也可以在详情面板点重新转写。

## 导出

**单条语音导出**
语音详情 → 导出音频，选择保存位置。

**整个会话导出**
语音列表右上角「导出」，得到 `audio/`、`manifest.json`、`transcript.md`、`index.csv`
和可离线打开的 `archive.html`。

## 数据与隐私

**文件放在哪**
媒体库默认「文档 / Sylk Library」，可在设置 → 媒体库修改。数据库、设置在
`%APPDATA%\app.sylk.desktop`；日志在 `%LOCALAPPDATA%\app.sylk.desktop\logs`，保留 14 天。

**怎么清空数据**
设置 → 隐私 → 清除本机数据：删除数据库记录、媒体文件、引擎登录态和日志，保留程序与设置。

**数据会出网吗**
只有五类：QQ 登录与消息、语音下载、群/好友头像加载、你主动开启的云端转写、你手动触发的
引擎包下载。没有遥测。完整清单见 [`privacy.md`](privacy.md)。

**卸载后数据还在吗**
卸载程序不会删除「文档 / Sylk Library」，需要手动删除；应用数据目录也可以手动清理。
