# 隐私与数据处理

Sylk 是本地优先的桌面应用：语音、转写文本、数据库和引擎登录态默认只存在这台电脑上。
这份文档说明数据具体放在哪、什么时候会出网、哪些保护已经做了、哪些没有做。

## 数据清单

| 数据 | 位置 | 是否敏感 | 说明 |
|---|---|---|---|
| QQ 账号、昵称、头像地址 | 应用数据目录 `sylk.db` | 是 | 登录后由引擎接口返回 |
| 会话名、群成员数、备注 | `sylk.db` | 是 | 用于会话列表与搜索 |
| 语音文件（WAV）与原始文件（SILK） | 媒体库 `audio/`、`raw/` | 是 | 默认在「文档 / Sylk Library」 |
| 转写文本 | `sylk.db` | 是 | 云端转写时音频会离开本机，见下文 |
| 星标、标签、备注 | `sylk.db` | 是 | 手动整理的内容 |
| 任务队列与错误信息 | `sylk.db` | 否 | 记录下载、转写失败原因 |
| 引擎登录态、QQ 缓存 | 引擎目录 `qqdata/` 等 | 是 | 第三方引擎写入，退出登录或清除数据时删除 |
| 日志 | `%LOCALAPPDATA%\app.sylk.desktop\logs` | 否（已脱敏） | 默认保留 14 天 |
| 设置 | `%APPDATA%\app.sylk.desktop\settings.json` | 部分 | 含媒体库路径、引擎路径；云端转写 API Key 加密存储 |

数据库是明文 SQLite。这一取舍的原因见文末「边界与局限」。

## 出网清单

Sylk 自身不向项目维护者的服务器发送数据，没有遥测，也没有自动更新检查。可能发生网络请求的只有：

1. **QQ 登录与消息收发**：由本机 QQ 客户端与 NapCat 完成，连接腾讯的服务器。
2. **语音下载**：从 QQ 的 CDN 拉取语音，地址由引擎提供。
3. **云端转写**（可选，默认关闭）：把选中语音的 WAV 发到你填写的 OpenAI 兼容接口。
4. **引擎包下载**（可选）：从你配置或内置的地址拉取第三方引擎包。

第 3、4 项的地址在保存设置时校验：必须使用 `https://`；只有 `127.0.0.1` / `localhost`
这类本机回环地址允许 `http://`。这样可以避免把音频或令牌发到明文通道。

## 密钥与令牌

- **云端转写 API Key**：使用 Windows DPAPI（当前用户作用域）加密后写入 `settings.json`，
  文件里是 `dpapi:` 开头的密文。换 Windows 账户或重装系统后解不开，需要重新填写。
- **引擎端口令牌**：每次启动由操作系统 CSPRNG 生成，只写入本机引擎配置文件；引擎只监听
  `127.0.0.1`；日志中出现本次令牌时会被替换成 `***`。
- **外部 NapCat 的令牌**：由你自己提供，存在 `settings.json`，Sylk 不写日志。

## 日志

- 语音内容、转写文本、备注不会写入日志。
- 引擎 stdout/stderr 进入界面前做脱敏：URL 里的 `access_token` / `token`、`Bearer` 令牌、
  Windows 用户目录（`C:\Users\<用户名>`）以及 QQ 号中间位都会被替换。
- 日志按天落盘，启动时删除 14 天前的文件。

## 截屏防护

设置 → 隐私 → 截屏防护，对应 Windows 的 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，
系统截屏、录屏和大部分屏幕捕获接口会得到黑屏窗口。它需要 Windows 10 2004 及以上。

这项功能**不是**防窥镜：屏幕共享由具体软件决定是否遵循该标记，管理员权限的进程也可以绕过；
它主要用于减少误截屏和普通录屏工具把内容录进去。

## 数据保留期

设置 → 隐私 → 自动清理：

- 选择 7 / 30 / 90 天后，启动约 10 秒执行一次清理，之后每 6 小时检查一次。
- 清理范围：超过期限的语音记录、对应的 WAV / SILK 文件，以及它们的下载与转写任务。
- 会话行会保留（只有名称，不包含语音内容），便于之后重新同步。
- 选择「不清理」则不做任何自动删除。

## 清除本机数据

设置 → 隐私 → 清除本机数据，会删除：

- 数据库中的账号、会话、语音、标签、备注与任务（`VACUUM` 回收空间）
- 媒体库中的 `audio/`、`raw/`、`exports/` 三个目录
- 引擎的 `qqdata/`、`cache/`、`logs/`、登录标记和按账号生成的配置
- 应用日志

会保留：程序本身、设置（引擎路径、媒体库位置、转写配置）、媒体库目录中不是 Sylk 生成的
文件。删除不可恢复；清理前建议先退出登录，并确认没有其他进程占用媒体库。

如需删除得更彻底，可以手动删除应用数据目录和媒体库目录，并在系统层面启用磁盘加密
（BitLocker 或 EFS）。SSD 的 TRIM、系统还原点、文件历史记录和云盘同步不在这份文档的控制范围内。

## 边界与局限

已经处理的问题：

- 远程地址强制 HTTPS（本机回环例外），避免明文传输。
- 引擎下载与解压有大小上限、条目数上限和路径越界检查，防止 zip 炸弹和目录穿越。
- 从数据库读取的媒体路径必须位于媒体库目录内，防止被改过的数据库读到任意文件。
- 播放器不使用 WebView 的文件读取协议，只经后端命令读取媒体库内的 WAV。
- WebView 配置了内容安全策略，禁用本地文件协议，发布版不开 DevTools。
- 引擎进程与窗口只绑定本机回环地址；关闭应用时回收整棵进程树。

没有处理、需要你了解的问题：

- **数据库未加密**：SQLite 文件是明文，依赖 Windows 账户隔离。能读取你用户目录的程序
  也能读取数据库。需要更强保护时，把应用数据目录放在 BitLocker 或 EFS 加密的磁盘上。
- **QQ / NapCat 是第三方组件**：登录态和账号安全由它们与腾讯决定，Sylk 不控制也不审计。
  第三方客户端的账号风险需要自行判断。
- **不防管理员权限或内核级恶意软件**：它们可以读取内存、注入进程、截屏或直接复制文件。
- **不防物理接触、系统备份、云同步**：这些路径上的副本不受 Sylk 管理。
- **删除不等于覆写**：文件删除后，磁盘底层数据是否可恢复取决于文件系统、TRIM 和磁盘加密。
- **截屏防护不覆盖屏幕共享与管理员进程**，见上一节。

如果你发现实现与本文不符，按 `SECURITY.md` 的方式私下报告。
