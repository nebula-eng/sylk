# 5 分钟快速开始

Sylk 是 Windows 桌面应用，官方安装包只提供 Windows x64。

## 0. 开始前确认

- Windows 10 2004+ 或 Windows 11，x64。
- 安装时需要联网补装 WebView2（Windows 11 通常自带）。
- 准备手机 QQ，用你的账号扫码登录。
- 准备一个能用的引擎。Sylk **不内置**第三方引擎，这是第一次使用唯一的额外步骤。

## 1. 安装 Sylk

从 [Releases](https://github.com/nebula-eng/sylk/releases/latest) 下载
`Sylk_<版本>_x64-setup.exe`，双击安装。安装包约 3 MB，安装到当前用户目录，不需要管理员权限。

安装包没有代码签名。Windows 提示「未知发布者」时，点「更多信息 → 仍要运行」。
部分安全软件可能拦截注入式引擎，需要自行判断是否放行。

## 2. 准备引擎

Sylk 通过 OneBot 11 读取 QQ 消息，需要一个引擎把 QQ 的数据暴露出来。
按你手里已有的东西选一条：

### 2.1 已经有兼容引擎包（便携 QQ）

目录里同时有 `QQ.exe`、`winmm.dll`、`snowcat-boot.js`、`napcat.mjs`，并保留
`native/`、`versions/` 等附属目录。保持原目录结构，不要只挑四个文件。

### 2.2 已经有 NapCat 目录

目录里能找到 `NapCatWinBootMain.exe`、`napcat.bat` 或 `napcat.mjs`。
经典 NapCat 注入只适用于较旧的 QQ；QQ 9.9.37-54395 起需要 V8 兼容引擎包。

### 2.3 已经有远程 OneBot 11

比如跑在另一台机器上的 NapCat。准备好 HTTP 地址和 WebSocket 地址；如果配置了 token，也准备好 token。

### 2.4 什么都没有

本项目**不提供第三方引擎下载**：NapCat 与兼容引擎包的许可不允许随仓库或安装包分发，
上游公开下载源目前也已失效。引擎的获取渠道、文件清单和组装方式写在
[`docs/engine.md`](engine.md) 的「获取与组装引擎包」一节。来源和账号风险需要自行判断。

## 3. 接入引擎

打开 Sylk。首次会停在「尚未配置引擎」，提供四种接法：

- **自动查找本机引擎**：扫描下载、桌面、文档、`%LOCALAPPDATA%\Sylk` 和各盘根目录，
  最多两层、3 秒上限，找到就直接用；
- **指定引擎目录**：手动选择兼容引擎包或 NapCat 目录，只校验、不搬动文件；
- **导入引擎包**：选择 zip，Sylk 解压到自己的数据目录并校验；兼容引擎包和 NapCat 包都认；
- **连接远程实例**：切到外部模式，到设置 → 连接里填 HTTP/WS 地址和 token。

接入后引擎会自动启动。如果使用外部实例，请先在设置 → 引擎把「接入方式」改为
「外部 NapCat」，再到「连接」页填写地址。

### 接入失败怎么办

- 自动查找没找到：用「指定引擎目录」直接选；扫描只覆盖常见目录和两层子目录。
- 导入 zip 报「没有找到兼容引擎包」：检查四个文件是否同目录、是否有 `QQ.exe`。
- 提示「文件已损坏」：QQ 版本与引擎不匹配，换 V8 兼容引擎包。
- 一直停在「启动阶段」：设置 → 引擎里能看到状态和日志。

## 4. 手机 QQ 扫码

引擎就绪后右侧显示二维码。用手机 QQ 扫码并确认。

二维码有效期约两分钟。过期后点一次「刷新二维码」；不要连续重启引擎，
短时间内反复登录会触发腾讯风控，提示「当前扫码操作存在安全风险」。

如果之前登录过，Sylk 会先尝试快速登录；60 秒没有进展会自动改用扫码，不需要手动处理。

## 5. 第一次同步与验证

登录成功后会自动同步会话列表；设置 → 引擎里的「登录后自动同步语音」默认开启，
会再拉取每个会话最近一页语音（只拉语音，不是全部聊天记录）。

- 某个会话没有语音：进入会话，点右上角「同步」；
- 想看同步结果：任务页有下载与转写进度、失败原因；
- 媒体库默认在「文档 / Sylk Library」，`audio/` 是 WAV，`raw/` 是可选的 SILK 原件；
- 点语音行左侧的播放按钮试听；详情面板可以加星标、标签、备注和转写。

## 可选：本机转写

如果要用本机 whisper.cpp：把 `whisper-cli.exe` 和 `ggml-*.bin` 放到
`%LOCALAPPDATA%\Sylk\tools`，然后在 设置 → 转写 里启用即可；Sylk 会自动找到这套文件。
源码环境可以运行：

```powershell
npm run setup:asr
```

默认下载 `base` 模型；中文要求更高时用 `powershell -File scripts/setup-asr.ps1 -Model small`。

## 6. 常见错误与下一步

| 现象 | 原因 / 下一步 |
|---|---|
| Windows 提示「未知发布者」 | 安装包未签名，点「更多信息 → 仍要运行」 |
| 双击没反应或白屏 | 确认 WebView2 已安装；从开始菜单启动；仍失败看 `%LOCALAPPDATA%\app.sylk.desktop\logs` |
| 找不到引擎 | 用「指定引擎目录」；自动查找只覆盖常见位置 |
| QQ 弹「文件已损坏」 | QQ 与引擎版本不匹配，换 V8 兼容引擎包 |
| 二维码空白 / 一直启动 | 等 60 秒自动回退扫码；或点一次「刷新二维码」 |
| 扫码提示安全风险 | 腾讯风控：停引擎，等 10–30 分钟再扫一次 |
| 音频还没下载 | 任务队列看原因，链接过期就「重试失败」或重新同步 |
| 转写不可用 | 设置 → 转写配置本机 `whisper-cli` 或 OpenAI 兼容接口 |

更多问题见 [`docs/faq.md`](faq.md)。

## 7. 卸载与清理

- **只清数据**：设置 → 隐私 → 清除本机数据；会删除数据库、媒体文件、引擎登录态和日志，
  保留程序与设置。
- **卸载程序**：安装目录 `%LOCALAPPDATA%\Sylk` 里的 `uninstall.exe`，或 Windows 设置 → 应用。
- 卸载不会自动删除「文档 / Sylk Library」，需要的话手动删除。

## 从源码运行

需要 Node.js 20+、Rust 1.80+、VS Build Tools（勾「使用 C++ 的桌面开发」）和 WebView2。

```bash
git clone https://github.com/nebula-eng/sylk.git
cd sylk
build.cmd
```

首次约 5–10 分钟。详细说明、开发模式和没有 QQ 的 mock 全链路见
[`docs/source-build.md`](source-build.md)。
