# 快速开始

Sylk 只支持 Windows。第一次使用需要两样东西：Sylk 本身，以及一个能用的引擎。
下面是两条路径，按你的身份选一条。

## 路径 A：只想用，不改代码

1. **装 Sylk**：从仓库 Releases 下载 `Sylk_<版本>_x64-setup.exe`，双击安装。
   安装包约 3 MB，装到当前用户目录，不需要管理员权限。
2. **准备引擎**：Sylk 不内置引擎，原因见下一节。你手里应该有下面任意一种：
   - 一个**兼容引擎包**目录（便携 QQ + 兼容层，同时含 `QQ.exe`、`winmm.dll`、
     `snowcat-boot.js`、`napcat.mjs`），
   - 或一个 **NapCat** 目录（含 `NapCatWinBootMain.exe` / `napcat.bat` / `napcat.mjs`），
   - 或一个已经在跑的 **OneBot 11 实例**（HTTP + WebSocket 地址和令牌）。
3. **打开 Sylk**：桌面图标或开始菜单搜「Sylk」，约 1 秒出界面。首次会停在引擎页，三种接法：
   - **自动查找本机引擎**：扫下载、桌面、文档、应用数据目录和各盘根目录，找到就直接用；
   - **指定引擎目录**：手动选兼容引擎包或 NapCat 目录，只校验不搬动文件；
   - **导入引擎包**：选一个 zip，Sylk 解压到自己的数据目录并校验；兼容引擎包和 NapCat 包都认；
   - 已经有远程 OneBot 实例就点「连接远程实例」，到设置里填地址和令牌。
4. **扫码登录**：引擎起来后显示二维码，用手机 QQ 扫码确认，之后自动同步会话。

装好之后，以后打开就是「双击图标 → 扫码/快速登录 → 用」。

### 兼容引擎包长什么样

同时满足以下四个文件在同一个目录，Sylk 就认它是兼容引擎包：

```
<引擎目录>/
├─ QQ.exe
├─ winmm.dll
├─ snowcat-boot.js
├─ napcat.mjs
├─ native/            （引擎自带的原生依赖，保持原样）
├─ versions/          （便携 QQ 的运行文件，保持原样）
└─ config/            （Sylk 启动时会重写 OneBot 配置）
```

从你获得该引擎包的渠道解压后保持原目录结构即可，不要只挑四个文件出来。
NapCat 目录的校验规则是能找到 `NapCatWinBootMain.exe`、`napcat.bat` 或 `napcat.mjs`。

## 路径 B：想改代码，从源码跑

需要 Node.js 20+、Rust（rustup）、VS Build Tools（勾「使用 C++ 的桌面开发」）、
WebView2 运行时。Windows 11 自带 WebView2，Windows 10 可能需要单独装。

```bash
git clone <仓库地址> sylk
cd sylk
build.cmd            # 或者 npm run setup
```

`build.cmd` 会检查工具链、装依赖、编译前端和 Rust、打安装包、装到本机、建桌面快捷方式。
第一次约 10 分钟，之后改代码再编约 3–4 分钟。中间长时间没输出是正常的。
它不会替你装 Node/Rust/VS Build Tools——缺什么会直接告诉你。

第一次编译完成后，引擎接入方式和路径 A 的第三步一样。

## 为什么引擎不能内置

这是第一次使用唯一的额外步骤，不是漏做的功能：

1. **许可限制**：NapCat、兼容引擎包及其修改版都带限制性许可，不允许在仓库或安装包里再分发。
   Sylk 使用 MIT 许可，不能把别人的受限二进制塞进来。
2. **上游状态**：NapCat 官方发布渠道在 2026-11 前后已清空，内置自动下载地址大概率不可用；
   兼容引擎包通常只在第三方仓库或群里流转，没有稳定的公开下载端点。
3. **QQ 依赖**：引擎需要本机安装的 QQ 客户端（兼容引擎包则自带便携 QQ）。
   QQ 本身也不能随 Sylk 分发。

所以 Sylk 把「引擎装在哪、怎么启动、怎么校验」做好，把「引擎从哪来」留给你。
安装包和仓库里都不含第三方引擎，这样仓库才能公开、安装包才会只有 3 MB。

## 常见问题

**自动查找没找到**
只会扫下载、桌面、文档、`%LOCALAPPDATA%\Sylk`、各盘根目录，最多两层子目录。
引擎包放在别处就用「指定引擎目录」直接选。扫描有 3 秒上限，机械硬盘上可能漏，重复点一次即可。

**导入 zip 报「没有找到兼容引擎包」**
包里的四个文件必须同目录，且要有 `QQ.exe`。只含 `napcat.mjs` 和插件的包不是完整引擎包，
用「指定引擎目录」选 NapCat 根目录，或改用「连接远程实例」。

**引擎起来了但 QQ 弹「文件已损坏」**
QQ 版本与引擎不匹配。经典 NapCat 通道对 QQ 9.9.37-54395 及以上不兼容，需要兼容引擎包；
Sylk 启动前会比对版本，不匹配时不会注入，登录页会写出两边版本。

**还是起不来**
登录页底部有「引擎日志」，设置 → 引擎 → 环境自检会列出引擎文件、QQ 版本、进程和登录状态。
把日志和自检结果一起提 issue，比只说「打不开」有用得多。

**登录失败、提示扫码有安全风险**
腾讯账号侧的风控。先停引擎，避免连续重试，等 10–30 分钟再扫一次。
登录成功后不要频繁点「退出登录 / 重启引擎」。
